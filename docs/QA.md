# Орбита — QA-протокол

Проверка проводится на двух устройствах/симуляторах с одной и той же сборкой.
Все тесты локальные: сеть, аккаунты и аналитика не используются.

## Установка

1. Android: установить `orbita-vX.Y-debug.apk` из артефакта CI или релиза.
2. iOS: установить `orbita-vX.Y-unsigned.ipa` через sideload ( без подписи App Store).
3. Убедиться, что имя приложения `Orbit`, Bundle ID `com.example.orbit`.

## Игровой цикл

| Проверка | Ожидаемый результат |
| --- | --- |
| Тап по полю | Смена орбиты, звук `tap`, лёгкая хаптика |
| Удержание >140 мс | Нырок на внутреннюю орбиту, возврат после отпускания |
| Сбор сфер | Рост счёта и комбо; x8 включает перегруз на 6 с |
| Близкий пролёт | +очки, искры, микро-замедление 120 мс |
| Каждые 5 уровней | Появление босса с тремя ядрами и счётчиком заряда |
| Метеоритный дождь | Предупреждение, сектор рядом с игроком свободен |
| Червоточины | Пара порталов переносит комету |
| 7 бонусов | Щит/замедление/магнит/x2/фаза/заморозка/второй шанс; не более двух активных |
| Клавиатура | Space/Enter, ←/→, Esc/P работают так же, как тап |

## Мета и сохранения

- Завершить забег: отчёт содержит очки, сферы, близкие пролёты, время, рекорд.
- Проверить 3 задания дня: прогресс и награда выдаются один раз.
- Набрать XP в сезоне: уровни открываются по порогам, награды забираются вручную.
- Новый рекорд: ghost-траектория появляется в следующем забеге.
- Экспорт/импорт `ORB1-...`: код переносит весь JSON v2, включая ghost и настройки.
- Сменить тему (ОБСЕРВАТОРИЯ/НЕОН/ЗАКАТ) и палитру: HUD и шейдер меняются синхронно.
- Уменьшить анимацию: тряска и зум отключаются, частицы уменьшаются.

## Паритет

- `pnpm run check:logic` — одинаковые 3000 шагов симуляции, ghost, лимит эффектов, одноразовые награды.
- `python3 tools/parity_report.py` — Android/iOS несут байт-идентичный web-бандл.
- Звук и хаптика — одни и те же M4A и пресеты на обеих платформах.

## Скриншоты

Автоматический захват экрана требует эмулятора Android или Xcode Simulator;
в текущем окружении их нет, поэтому скриншоты не генерируются искусственно.
Для ручного захвата: открыть меню, забег и отчёт на каждом устройстве,
сохранить изображения в `docs/screenshots/<version>/<platform>/`.
