# Орбита 3.5 — Legend Edition

Неоновая аркада про корабль на орбите планеты. Нативная реализация: Android — Kotlin + Jetpack Compose, iOS — SwiftUI + Canvas. Полный паритет механик, экранов, прогрессии, ресурсов и звука между платформами.

## Ядро геймплея (сохранено из v3.0)

- **Тап** меняет направление полёта — основа управления.
- **Астероиды и кометы** летят из космоса; кометы со 2 уровня, быстрее и ценнее.
- **Близкий пролёт** даёт бонус за риск, вспышку и микро-замедление.
- **Сферы**: обычные, золотые и редкие артефакты.
- **Бонусы**: щит, замедление, двойные очки, магнит, фаза, заморозка, второй шанс.
- **Комбо** до x8 с кольцом-таймером вокруг планеты.
- **Уровни** каждые 50 очков: рост скорости и плотности.
- **Метеорный дождь** с предупреждением и безопасным окном.
- **Столкновение** — конец забега; щит и второй шанс спасают один раз.
- Вибрация (настраивается), пауза, локальный рекорд.

## Что добавлено в 3.5

### Пять режимов с собственной логикой

| Режим | Суть |
|---|---|
| **КЛАССИКА** | Бесконечный полёт, одна ошибка — конец |
| **ДЗЕН** | 90 секунд без астероидов, только сферы и бонусы |
| **СПРИНТ** | 60 секунд на максимум очков; удар стоит 3 секунды |
| **ВЫЖИВАНИЕ** | Плотность растёт непрерывно, старт с 3 уровня |
| **ДЕЙЛИ** | Фиксированный сид дня, общий вызов для всех игроков |

### Восемь секторов

ОРБИТА-01 → ПЕПЕЛ → НЕОНОВЫЙ ПОЯС → ЛЕДЯНОЕ КОЛЬЦО → СЕРДЦЕ ШТОРМА → ЧЕРВОТОЧИНА → ЯДРО ГИГАНТА → скрытый СЕКРЕТ. У каждого свои опасности: кометы, мины, гравитационные колодцы, солнечные вспышки, червоточины, боссы и плотность.

### Новые угрозы и объекты

- **Мины** — медленные, но смертельные, с пульсирующим предупреждением.
- **Гравитационные колодцы** — притягивают астероиды к своей орбите.
- **Солнечные вспышки** — залпы быстрых лучей по всему кольцу.
- **Червоточины** — пары порталов, телепортирующие корабль.
- **Босс-ядро** — с health-bar, стреляет залпами, сбивается сферами в его секторе.
- **Семь бонусов** (было три): щит, замедление, x2, магнит, фаза, заморозка, второй шанс.
- **Призрак** — запись траектории последнего забега (4096 точек, детерминированный сид).

### Мета-прогрессия

- Опыт, уровень игрока, жетоны и сезонные награды.
- **21 предмет** в магазине: 8 корпусов, 4 шлейфа, 4 планеты, 5 улучшений.
- **18 достижений** и **6 секретов** с наградами; скрытый сектор открывается через секреты.
- **3 задания дня** (детерминированно по UTC-дате), серия дней, авто-начисление после забега.
- **Сезон** — 4 уровня с наградами, обновляется каждые 56 дней.
- Статистика: забеги, очки, сферы, боссы, порталы, топ-10 по каждому режиму, история 25 забегов.
- Локальная таблица рекордов по режимам.

### Экраны

Хаб с выбором режима/сектора, ангар с предпросмотром корабля и планеты, магазин, задания и сезон, достижения и секреты, статистика с историей и рекордами, настройки, пауза, результаты с разбором наград и всплывающие тосты.

### Графика и звук

- **48 спрайтов/текстур** PNG (8 фонов, 8 планет, 8 кораблей, 8 астероидов, 3 кометы, 7 бонусов, 3 сферы, 3 FX) — идентичные файлы на обеих платформах.
- **35 WAV**: 8 музыкальных треков по 48 секунд и 26 SFX (тап, уклонение, сфера, бонус, щит, краш, уровень, шторм, UI, награда, достижение, покупка, босс, портал, вспышка, магнит, фаза, заморозка, ревайв, секрет, победа, поражение и др.).
- Музыка переключается по секторам и cycling-трекам; раздельные громкости музыки и эффектов, полное выключение.
- Частицы, вспышки, тряска, свечение, шлейфы, микроанимации. Опция «уменьшить анимацию» для доступности.

### Надёжное сохранение

JSON v3 с валидацией, резервной копией, восстановлением, экспортом/импортом кода с CRC32 (`ORB1-...`), автосохранением после каждого действия и забега. Настройки и прогресс не теряются при битом файле.

## Генерация ресурсов

```bash
python3 tools/generate_assets.py   # PNG + WAV сразу в Android res/ и iOS Resources/
```

Генератор детерминирован, использует только стандартную библиотеку Python и создаёт **идентичные** файлы для обеих платформ.

## Структура

```
app/src/main/java/com/example/orbit/
  game/       Content, Entities, GameEngine — контент и детерминированная симуляция
  data/       SaveStore — JSON v3, прогресс, задания, сезон, экспорт/импорт
  ui/         GameRenderer (спрайты, VFX), GameScreen (хаб и все экраны)
  audio/      SoundEngine — 8 треков, 26 SFX, громкости
app/src/main/res/drawable-nodpi/   PNG (зеркало iOS)
app/src/main/res/raw/              WAV (зеркало iOS)
ios/Orbit/  Content, Entities, GameEngine, GameRenderer, ContentView,
            SaveStore, SoundEngine
ios/Orbit/Resources/               те же PNG/WAV
tools/generate_assets.py           генератор ресурсов
```

## Сборка

**Android** — `orbita-debug-apk` в GitHub Actions на каждый пуш.

**iOS** — CI на macOS собирает симулятор и unsigned device IPA (`orbita-unsigned-ipa`). Для установки на iPhone используй AltStore/Sideloadly — они переподпишут IPA твоим Apple ID. Для TestFlight см. [RELEASE.md](RELEASE.md).

**Релиз** — тег `vX.Y` публикует релиз с обоими артефактами. Текущая рабочая ветка `v3-legend` тегов не создаёт, пока не попросят.
