# ORBITA GALAXY

Новое направление проекта — **одиночная .io-вдохновлённая космическая арена на Unity**: огромная карта, рост и поглощение, 20–35 локальных ботов с utility AI, эволюции, боссы, живые события и глубокая мета-прогрессия. Никаких серверов, аккаунтов и сетевого PvP — весь мир симулируется локально.

- **Активная ветка:** `galaxy-main`. Код лежит в [`unity/Assets/OrbitGalaxy/`](unity/Assets/OrbitGalaxy/), тесты — в [`unity/Tests/Galaxy/`](unity/Tests/Galaxy/), релизы публикуются по тегам `g*`.
- **Гайд по игре и разработке:** [`docs/GALAXY_README.md`](docs/GALAXY_README.md).
- **Аудит и план миграции:** [`docs/GALAXY_MIGRATION.md`](docs/GALAXY_MIGRATION.md). Публичный контракт ядра: [`docs/GALAXY_CONTRACT.md`](docs/GALAXY_CONTRACT.md).
- **Старая Unity-аркада:** [`unity/Assets/Orbit/`](unity/Assets/Orbit/) заморожена, ветка `unity-main`, теги `u*` и релиз `u4.0.0` остаются без изменений.
- **Нативная v3.8.0:** последний опубликованный baseline, исходники в `app/` и `ios/Orbit/`; теги `v*`, включая `v4.0`/`v4.1`, не трогаются.

Подробности по Unity-проекту, тестам и секретам сборки — в [`unity/README.md`](unity/README.md).

## Доступные режимы

`КЛАССИЧЕСКАЯ АРЕНА`, `ВЫЖИВАНИЕ`, `ОХОТА НА БОССОВ`, `ХАОС`, `ХАРДКОР`, `БЕСКОНЕЧНОСТЬ` — у каждого свои параметры арены, опасности и награды.

## Ядро геймплея (сохранено из v3.0)

- **Тап** меняет направление полёта — основа управления.
- **Астероиды и кометы** летят из космоса; кометы со 2 уровня, быстрее и ценнее.
- **Близкий пролёт** даёт бонус за риск, вспышку и микро-замедление.
- **Сферы**: обычные, золотые и редкие артефакты.
- **Бонусы**: щит, замедление, двойные очки, магнит, фаза, заморозка, второй шанс.
- **Комбо** до x8 с кольцом-таймером вокруг планеты.
- **Уровни** каждые 50 очков: рост скорости и плотности.
- **Метеорный дождь** с предупреждением и безопасным окном.
- **Столкновение** — конец забега; щит и второй шанс спасают один раз.
- Вибрация (настраивается), пауза, локальный рекорд.

## Что добавлено в 3.8

- **Шестой режим «ШТАБЕЛЬ»**: 10×18, 7-bag тетромино, hold, очередь следующей фигуры, привидение-контур, жёсткое падение, очистка линий, комбо и рост скорости каждые 8 строк.
- **Настоящая аркадная подача**: огромный логотип и счёт, плавающие чипы HUD, яркая игровая арена, толстые фигуры, крупная кнопка старта — вместо набора карточек и форм.
- **Управление штабелем**: свайп влево/вправо — движение, свайп вниз — мягкое падение, свайп вверх — поворот, тап по нижней зоне — хард дроп; на обеих платформах есть плавающая панель кнопок.
- **Видимая мотивация**: топ-3 по режиму прямо на главном экране, цель забега, сезонный прогресс, жетоны и streak без лишних экранов-инструкций.

### Шесть режимов с собственной логикой

| Режим | Суть |
|---|---|
| **КЛАССИКА** | Бесконечный полёт, одна ошибка — конец |
| **ДЗЕН** | 90 секунд без астероидов, только сферы и бонусы |
| **СПРИНТ** | 60 секунд на максимум очков; удар стоит 3 секунды |
| **ВЫЖИВАНИЕ** | Плотность растёт непрерывно, старт с 3 уровня |
| **ДЕЙЛИ** | Фиксированный сид дня, общий вызов для всех игроков |
| **ШТАБЕЛЬ** | Падающие тетромино: линии, комбо, hold и скорость |

### Десять секторов

ОРБИТА-01 → ПЕПЕЛ → НЕОНОВЫЙ ПОЯС → ЛЕДЯНОЕ КОЛЬЦО → СЕРДЦЕ ШТОРМА → ЧЕРВОТОЧИНА → ЯДРО ГИГАНТА → скрытый СЕКРЕТ → ПОЛЯРНАЯ КОРОНА → СИНГУЛЯРНОСТЬ. У каждого свои опасности: кометы, мины, гравитационные колодцы, солнечные вспышки, червоточины, боссы и плотность.

### Новые угрозы и объекты

- **Мины** — медленные, но смертельные, с пульсирующим предупреждением.
- **Гравитационные колодцы** — притягивают астероиды к своей орбите.
- **Солнечные вспышки** — залпы быстрых лучей по всему кольцу.
- **Червоточины** — пары порталов, телепортирующие корабль.
- **Три типа боссов** — ЯДРО, РОЙ и ИМПУЛЬС: с health-bar, разными залпами и сбиваются сферами в его секторе.
- **Семь бонусов** (было три): щит, замедление, x2, магнит, фаза, заморозка, второй шанс.
- **Призрак** — запись траектории последнего забега (4096 точек, детерминированный сид).

### Мета-прогрессия

- Опыт, уровень игрока, жетоны и сезонные награды.
- **25 предметов** в магазине: 8 корпусов, 4 шлейфа, 8 планет, 5 улучшений.
- **19 достижений** и **6 секретов** с наградами; скрытый сектор открывается через секреты.
- **3 задания дня** (детерминированно по UTC-дате), серия дней, авто-начисление после забега.
- **Сезон** — 4 уровня с наградами, обновляется каждые 56 дней; сезонный модификатор меняет плотность угроз.
- **Резонанс** — шкала заполняется сферами и бонусами, волна очищает пространство у орбиты и даёт очки.
- **Скины планеты** — Земля, Марс, Юпитер, Нептун, Венера, Сатурн, Луна и Экзо.
- Статистика: забеги, очки, сферы, боссы, порталы, топ-10 по каждому режиму, история 25 забегов.
- Локальная таблица рекордов по режимам.

### Экраны

Хаб с живой открыткой неподвижной орбиты, выбором режима/сектора, ангаром с предпросмотром корабля и планеты, магазином, заданиями и сезоном, достижениями и секретами, статистикой с историей, локальным топом и экспортом кода, настройками, паузой, результатами с разбором наград и всплывающими тостами.

### Графика и звук

- **48 спрайтов/текстур** PNG (8 фонов, 8 планет, 8 кораблей, 8 астероидов, 3 кометы, 7 бонусов, 3 сферы, 3 FX) — идентичные файлы на обеих платформах.
- **35 WAV**: 8 музыкальных треков по 48 секунд и 26 SFX (тап, уклонение, сфера, бонус, щит, краш, уровень, шторм, UI, награда, достижение, покупка, босс, портал, вспышка, магнит, фаза, заморозка, ревайв, секрет, победа, поражение и др.).
- Музыка переключается по секторам и cycling-трекам; раздельные громкости музыки и эффектов, полное выключение.
- Частицы, вспышки, свечение, шлейфы, микроанимации; орбита и планета остаются неподвижными, угрозы летят по радиальным коридорам.
- Доступность: уменьшение анимации, контрастные цвета, крупный текст, отдельные профили звука и вибрации.

### Надёжное сохранение

JSON v4 с версионной миграцией из v3, валидацией, резервной копией, восстановлением, экспортом/импортом кода с CRC32 (`ORB1-...`), автосохранением после каждого действия и забега. Настройки и прогресс не теряются при битом файле.

## Генерация ресурсов

```bash
python3 tools/generate_assets.py   # PNG + WAV сразу в Android res/ и iOS Resources/
```

Генератор детерминирован, использует только стандартную библиотеку Python и создаёт **идентичные** файлы для обеих платформ.

## Структура

```
app/src/main/java/com/example/orbit/
  game/       Content, Entities, GameEngine, BlockArena — контент и детерминированная симуляция
  data/       SaveStore — JSON v4 с миграцией v3, прогресс, задания, сезон, экспорт/импорт
  ui/         GameRenderer (спрайты, VFX), GameScreen (хаб и все экраны)
  audio/      SoundEngine — 8 треков, 26 SFX, громкости
app/src/main/res/drawable-nodpi/   PNG (зеркало iOS)
app/src/main/res/raw/              WAV (зеркало iOS)
ios/Orbit/  Content, Entities, GameEngine, BlockArena, GameRenderer, ContentView,
            SaveStore, SoundEngine
ios/Orbit/Resources/               те же PNG/WAV
tools/generate_assets.py           генератор ресурсов
```

## Сборка

**Android** — `orbita-debug-apk` в GitHub Actions на каждый пуш.

**iOS** — CI на macOS собирает симулятор и unsigned device IPA (`orbita-unsigned-ipa`). Для установки на iPhone используй AltStore/Sideloadly — они переподпишут IPA твоим Apple ID. Для TestFlight см. [RELEASE.md](RELEASE.md).

**Релиз** — тег `vX.Y` публикует релиз с обоими артефактами. Текущая версия `3.8` публикуется тегом `v3.8.0`; ветки `v4.x` из Capacitor-проекта не затрагиваются.
