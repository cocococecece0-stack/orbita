# Орбита

Неоновая аркада для Android на Kotlin + Jetpack Compose. Всё рисуется на `Canvas`, без картинок и сторонних движков.

## Геймплей

Корабль летит по орбите вокруг планеты. Навстречу, из глубины космоса, летят астероиды.

- **Тап по экрану** — сменить направление полёта (по часовой / против)
- **Астероид пролетел мимо** — +1 очко
- **Собрал золотую сферу** — +3 очка
- Столкновение — конец игры, рекорд сохраняется

Чем больше очков, тем быстрее астероиды и чаще спавн.

## Что внутри

- Игровой цикл на `withFrameNanos`, фиксированный шаг с клампом `dt`
- Собственный движок: орбитальная кинематика, радиальные траектории, коллизии по окружностям
- Партиклы, след корабля, тряска экрана, пульсация планеты, мерцающее звёздное поле
- DataStore для рекорда, пауза при уходе приложения в фон
- Haptic feedback на сбор сферы и столкновение
- Material 3, тёмная неоновая тема, edge-to-edge

## Сборка

APK собирается в GitHub Actions при каждом пуше:

1. Вкладка **Actions** → запуск **Build**
2. Артефакт **orbita-debug-apk**
3. Установить `app-debug.apk` (разрешить установку из неизвестных источников)

Локально (нужен Android SDK):

```bash
./gradlew assembleDebug
```

## Стек
